# Manual Requirement Input (Offline Fallback)

This file is used by the Requirement Agent (scripts/generate_requirements.js)
ONLY when the live JIRA connection is unavailable (no .env credentials, JIRA
down, or network blocked). When JIRA is reachable, requirements are always
fetched from the ticket and this file is ignored.

To use this fallback for a ticket, replace the content below with the
requirements for that ticket. The Requirement Agent will produce
artifacts/{JIRA_ID}/requirements.json from it.

---
